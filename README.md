# PM_sheet — 個人・売上・利益率計算表（Google Apps Script）

案件ごとの売上・原価・利益率と、担当者ごとの稼働率・負荷を可視化するための
Google Apps Script（GAS）製の計算表です。

このリポジトリは **コードのみ** を管理します（clasp によるデプロイ連携は行いません）。
コードの反映は、下記の手順で Apps Script エディタに手動でコピーしてください。

## できること

- 案件ごとの売上・原価・粗利益・利益率の自動計算
- 案件別集計（売上合計・原価合計・粗利益合計・平均利益率）
- 担当者別集計（担当案件数・売上・利益率・稼働率・要注意案件数）
- 稼働率 = 担当案件の稼働日数（人日）合計 ÷ 月間稼働可能日数
- 要注意案件・稼働過多な担当者を自動でハイライト
- ダッシュボードで全体の 売上／粗利益／利益率／案件数／要注意案件／メンバー数 を一覧表示

「私が・何を・どれだけ担当し・どんな成果を出したか」を後から説明できるように、
案件単位・担当者単位の両方で集計を残す設計にしています。

## ファイル構成

```
gas/
  appsscript.json   # マニフェスト（参考用）
  Config.gs         # シート名・列定義・しきい値などの設定
  Main.gs           # メニュー登録、セットアップ/集計更新のエントリーポイント
  SetupSheets.gs    # 各シートの初期作成・書式・入力規則
  Aggregate.gs      # 案件別集計・担当者別集計・ダッシュボードの計算ロジック
```

## セットアップ手順

1. Google Drive で新規の Google スプレッドシートを作成する
2. メニューの「拡張機能」→「Apps Script」を開く
3. デフォルトで存在する `Code.gs` の中身を削除する
4. `gas/` フォルダ内の各ファイル（`Config.gs` / `Main.gs` / `SetupSheets.gs` / `Aggregate.gs`）を
   同じファイル名でスクリプトエディタに追加し、内容をコピーする
   （`appsscript.json` はプロジェクトの設定アイコン「⚙」→「マニフェスト ファイルを表示する」を
   有効にすると編集できます。タイムゾーンなどの参考としてご利用ください）
5. 保存してスプレッドシートに戻り、ページを再読み込みする
   （メニューバーに「案件管理」が表示されます）
6. メニュー「案件管理」→「① 初期セットアップ（シート作成）」を実行する
   - 初回実行時は Google アカウントへの権限承認が必要です
   - 「案件入力」「担当者マスタ」「案件別集計」「担当者別集計」「ダッシュボード」の
     5シートが作成されます
7. 「案件入力」シートに案件データを入力する
8. 必要に応じて「担当者マスタ」シートに担当者名と月間稼働可能日数を登録する
   （未登録の担当者は既定値 20日/月 で計算されます）
9. メニュー「案件管理」→「② 集計を更新」を実行すると、
   案件別集計・担当者別集計・ダッシュボードが最新の内容に更新されます

## シート構成

### ① 案件入力

| 列 | 内容 | 備考 |
|---|---|---|
| 案件No. | 任意の管理番号 | 手入力 |
| 案件名 | | 手入力 |
| 担当者 | | 手入力 |
| 状況 | 進行中／完了／保留／要注意 | プルダウン選択 |
| 売上（製作費予算） | | 手入力 |
| 外注費 | | 手入力 |
| 人日単価 | 1人日あたりの単価 | 手入力 |
| 稼働日数（人日） | その案件にかかった/かかる人日数 | 手入力 |
| 人件費 | 人日単価 × 稼働日数 | 自動計算 |
| その他原価（社内外注費） | | 手入力 |
| 原価合計 | 外注費 + 人件費 + その他原価 | 自動計算 |
| 粗利益 | 売上 − 原価合計 | 自動計算 |
| 利益率 | 粗利益 ÷ 売上 | 自動計算（15%未満は赤くハイライト） |
| 請求日 | | 手入力 |
| 課題・備考 | 記入があると自動的に「要注意」扱い | 手入力 |

### ② 担当者マスタ

| 列 | 内容 |
|---|---|
| 担当者名 | 「案件入力」の担当者と一致させる |
| 月間稼働可能日数 | 稼働率計算の分母（未登録なら既定値20日） |

### ③ 案件別集計（自動生成）

案件ごとの売上・原価合計・粗利益・利益率・要注意フラグに加え、
シート下部に売上合計・原価合計・粗利益合計・平均利益率を表示します。

### ④ 担当者別集計（自動生成）

担当者ごとの案件数・売上合計・粗利益合計・平均利益率・稼働日数合計・
稼働率・要注意案件数と、「稼働過多」「低利益率案件が多い」の自動フラグを表示します。

### ⑤ ダッシュボード（自動生成）

全体の 売上／粗利益／利益率／案件数／要注意案件／メンバー数 を一覧表示します。

## しきい値の変更

`gas/Config.gs` の以下の定数を変更することで、要注意判定の基準を調整できます。

- `LOW_MARGIN_THRESHOLD`：利益率がこれ未満の案件を「要注意」とする（既定 15%）
- `OVERLOAD_THRESHOLD`：稼働率がこれを超えたら「稼働過多」とする（既定 100%）
- `AT_RISK_RATIO_THRESHOLD`：担当案件のうち要注意案件がこの割合以上なら
  「低利益率案件が多い」とする（既定 50%）
- `DEFAULT_MONTHLY_CAPACITY_DAYS`：担当者マスタ未登録時の月間稼働可能日数（既定 20日）
